# NovaJolt

Automates custom network scans on local systems for known vulnerability exploits and outdated software.

With NovaJolt, you get a lightweight tool that stays out of your way.

**What you get**

- Automates custom network scans on
- local systems for known vulnerability
- exploits and outdated software

## Key Features

- Automates custom network scans on
- local systems for known vulnerability
- exploits and outdated software

## Technology Stack

- python
- Modular architecture
- CI-ready (GitHub Actions)

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/NovaJolt.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

To configure NovaJolt, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
